# doc2speech

A lightweight Python utility that reads text and documents aloud with any OpenAI-compatible text-to-speech server.

## Prerequisites

- Python 3.9 or newer
- ffmpeg on PATH (joins the audio parts of long texts)
- A server with an OpenAI-compatible `/audio/speech` endpoint and a **text-to-speech model**
